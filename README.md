# Momcozy AI B-lane Android test downloads

This public repository serves **sideload test APKs**, not Google Play releases. The QR code on the GitHub Pages site and the clickable QR image point to the immutable versioned APK GitHub Release asset. It does not contain backend credentials or source code.

Build 1.0.0 (70) is derived from the verified signed B CI Android AAB at app commit `90f525c41dfd7ef3c5474992d78302971aae74a8`, workflow run `37256511229`. See `manifest.json` and the release `.sha256` and `.provenance.json` files for verification.

The APK is signed with the Play upload certificate. Google Play may deliver a differently signed APK, so changing from this sideload test build to Play may require uninstalling it. The public page is not access-controlled; do not share it as a private testing channel.
